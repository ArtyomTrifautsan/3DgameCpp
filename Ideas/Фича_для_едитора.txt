Я хочу реализовать создание карт с помощью загрузки моделей, создание для них объектов коллизий
и сохранение в файл.

Фичи которые нужны:
1) Загрузка модели по пути.
2) Создание объекта коллизии (или нескольких)
3) Возможность переключаться между моделями и между объектами коллизий
4) Движение этих объектов в editor (а также поворот и resize)
5) Возможность объединять одну или несколько моделей и объектов коллизий в единую сущность (предположительное название сущности - game_object) 
5) Сохранение в файл в специальном формате, чтобы потом можно было импортировать в игре
6) Импорт таких объектов из файла в editor


Какие будут нужны инстурменты:
1) Класс для хранения всех элементов -- Scene
3) Класс загрузки 3д моделей с помощью пути -- ModelLoader
3) Класс для создания объектов коллизий -- CollideObjectCreator
4) Класс для создания game_object'ов -- GameObjectCreator
2) Класс импорта и экспорта game_object'ов
5) Класс для движения, вращения и изменения размеров как отдельных моделей и объектов коллизий, так и целых game_object'ов -- SceneObjectController


Как я вижу процесс создания карты.
1. Запускаю editor
2. Загружаю 3д модель из файловой системы. Здесь отрабатывает класс ModelLoader, который ищет модель в файловой системе и загружает ее в память
   с помощью ResourceManager'а. Далее эту модель он прокидывает в Scene. 
3. Создаю объект коллизии. CollideObjectCreator создает объект нужного подтипа и передает в Scene
4. Двигаю модель и объект коллизии по отдельности. Тут работает класс
